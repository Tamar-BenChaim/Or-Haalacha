# server – שרת ה־API

שרת Node.js (Express 5) שמשרת את החנות ואת אזור הניהול. תיעוד הנקודות: [docs/api.md](../docs/api.md).

## הרצה מקומית

דרישות: Node.js 22.9 ומעלה.

```bash
cd server
npm install
cp .env.example .env     # למלא ערכים מקומיים; הקובץ לא נכנס ל־git
npm run dev              # מריץ עם טעינה מחדש בכל שינוי
```

השרת לא עולה אם משתנה סביבה חסר או לא תקין, ומדפיס את שם המשתנה (בלי הערך).

## פקודות

| פקודה            | מה עושה                                       |
| ---------------- | --------------------------------------------- |
| `npm run dev`    | הרצה לפיתוח, טוען את `.env`                   |
| `npm start`      | הרצה לייצור (משתני הסביבה מגיעים מהשרת המארח) |
| `npm test`       | בדיקות יחידה ואינטגרציה (Vitest + Supertest)  |
| `npm run lint`   | ESLint ובדיקת עיצוב Prettier                  |
| `npm run format` | סידור הקוד לפי Prettier                       |

## מבנה

```
src/
  server.js        הפעלה: טעינת הגדרות, האזנה וכיבוי מסודר
  app.js           בניית אפליקציית Express (בלי האזנה, בשביל הבדיקות)
  config/          אימות משתני הסביבה עם zod
  middleware/      אבטחה, מזהה בקשה, לוג בקשות, אימות קלט, שגיאות
  routes/          הגדרת הנתיבים וחיבור השכבות
  controllers/     קריאת הבקשה והחזרת תשובה
  services/        הלוגיקה העסקית
  logging/         מאגרי הלוגים (כרגע פלט השרת, בהמשך מסד הנתונים)
  lib/             כלים משותפים
test/
  unit/            בדיקות יחידה
  integration/     בדיקות של האפליקציה כולה דרך HTTP
```

סדר השכבות: routes → controllers → services → data access. כל שכבה מקבלת את התלויות שלה כפרמטר, וכך קל לבדוק אותה בנפרד.

## אבטחה

- כותרות אבטחה (helmet), ‏CORS רק לכתובות שב־`CORS_ORIGINS`, הגבלת קצב לכל כתובת IP.
- גוף בקשה עד 100KB, ו־JSON בלבד.
- דחיית שמות שדות שמתחילים ב־`$` או מכילים `.`, וגם `__proto__` ודומיו (NoSQL injection ו־prototype pollution).
- אימות קלט לכל נקודה עם `validate({ params, query, body })` וסכמות zod. הערכים המאומתים נמצאים ב־`req.validated`.
- שגיאה לא צפויה מחזירה ללקוח הודעה כללית עם מזהה בקשה. הפרטים נשמרים רק בלוג.

## לוגים

כל בקשה נרשמת בסיומה: זמן, מזהה בקשה, שיטה, נתיב (בלי פרמטרים), סטטוס, משך וכתובת IP מקוצרת. לא נרשמים גוף הבקשה, כותרות או פרטים אישיים. כשל ברישום לא פוגע בבקשה. ראו החלטה [0007](../docs/decisions/0007-server-logging.md).
