# אפיון – החלטות ושאלות פתוחות

מסמך עבודה שמרכז את מה שהוחלט בשלב התכנון, ואת מה שעוד צריך לברר.

## פרטי העסק

- **דומיין:** orhaalacha.org
- **מייל העסק:** support@orhaalacha.org (כל החשבונות בשירותים ייפתחו על המייל הזה)

## החלטות

| נושא | החלטה |
|------|-------|
| משתמשים | אין הרשמה ואין התחברות לקונים |
| עגלה | נשמרת בדפדפן |
| תשלום | דרך חברת סליקה חיצונית, עדיפות לחברה שמפיקה קבלות/חשבוניות אוטומטית |
| אחרי התשלום | מייל אישור לקונה עם מספר הזמנה, והודעה לבעל העסק על הזמנה חדשה |
| מעקב הזמנה | מייל אוטומטי לקונה כשההזמנה מסומנת בניהול כ"נשלחה" |
| נגישות | מתוכננת מההתחלה, לפי ת"י 5568 (WCAG 2.0 AA) |
| מסמכים משפטיים | תקנון, מדיניות פרטיות, ומדיניות ביטולים והחזרות – מתוכננים במקביל לאפיון |
| תוכן | בשלב זה עובדים עם תוכן לדוגמה (ספרים, תמונות, מחירים ולוגו) |
| ניהול האתר | אפליקציית ניהול נפרדת בכתובת `admin.orhaalacha.org`, בלי שום קישור מהחנות |
| גישה לניהול | מנהל אחד (support@orhaalacha.org). שתי שכבות הגנה: שער Cloudflare Access עם קוד למייל, ובדיקת התחברות בשרת לכל פעולת ניהול |
| יכולות הניהול | ספרים (הוספה, עריכה, הסתרה, מחיר, תמונה, מלאי) והזמנות (רשימה, סינון ועדכון סטטוס) |

## דף הבית

מבנה (מלמעלה למטה):
1. פס הודעה עליון – אופציונלי, נערך מאזור הניהול.
2. כותרת עליונה: לוגו, תפריט (הספרים · אודות · צור קשר), אייקון עגלה עם מספר פריטים.
3. אזור פתיחה: שם הסדרה, תיאור קצר, כפתורים "לכל הספרים" ו"הסט המלא".
4. כל הספרים (כ־20) ישירות בדף הבית, בלי דף קטלוג נפרד. כרטיס ספר: כריכה, שם, תיאור קצר, מחיר, "הוספה לעגלה". ספר שאזל מסומן, והכפתור לא פעיל.
5. הסט המלא במחיר מיוחד.
6. על הסדרה – פסקה קצרה וקישור לדף "אודות" (אפשר עם תמונות מהשיעורים של הרב המחבר).
7. למה לקנות כאן: תשלום מאובטח · קבלה אוטומטית · משלוח עד הבית.
8. כותרת תחתונה: מייל, טלפון, קישורים לתקנון, פרטיות, ביטולים והחזרות, הצהרת נגישות.

נגישות: ניווט מקלדת, "דילוג לתוכן הראשי", טקסט חלופי, ניגודיות לפי התקן, בלי "תוסף נגישות" צף.

עיצוב: שלושה כיוונים בהדמיה, לבחירת הלקוח – קלאסי (כחול וזהב), כריכת עור (בורדו ושמנת), נקי ומינימלי (לבן וירוק כהה).

## דף ספר

1. פירורי לחם: דף הבית › שם הספר.
2. תמונות: כריכה גדולה ותמונות קטנות מתחת, עם אפשרות הגדלה.
3. פרטים: שם ומספר כרך, מחיר, זמינות (במלאי / אזל), בחירת כמות, "הוספה לעגלה", קישור לסט המלא.
4. תיאור מלא של הספר.
5. פרטים טכניים (מספר עמודים, גודל, כריכה, שנת הוצאה) – בהדמיה, לאישור הלקוח.
6. עיון בספר – עמודים לדוגמה – בהדמיה, לאישור הלקוח.
7. מעבר לכרך הקודם / הבא, ושורת ספרים נוספים מהסדרה.
8. שיתוף: כתובת קבועה לכל ספר, תצוגה מקדימה עשירה ב־WhatsApp ובמייל (תמונה, שם, מחיר), וכפתור שיתוף.
9. הזמנה מוסדית / הנחת כמות – בהדמיה, לאישור הלקוח.
10. הוספה לעגלה פותחת עגלה קטנה מהצד ("להמשך קנייה" / "לתשלום"), כמו בדף הבית.

## בדיון

- **אחסון (יוחלט בשלב ההחלטות הטכניות):** האתרים כנראה ב־Cloudflare Pages. לשרת יושוו AWS ושרתים מנוהלים, לפי מחיר, פשטות, אבטחה וכתובת IP קבועה לחיבור ל־MongoDB Atlas.

## שאלות פתוחות ללקוח

- **חשבוניות:** סוג העוסק (פטור / מורשה / חברה), והאם כבר יש מערכת להפקת חשבוניות.
- **משלוחים:** אילו אפשרויות (עד הבית, נקודות איסוף, איסוף עצמי), מחירים, ומשלוח חינם מעל סכום מסוים?
- **ביטולים והחזרות:** מה המדיניות הרצויה?
- **תוכן:** תמונות הספרים, תיאורים, מחירים ולוגו.
- **סט מלא:** מחיר הסט.
- **עיצוב:** איזה משלושת הכיוונים בהדמיה?
- **טלפון:** מספר להצגה באתר.
- **אודות:** טקסט על הסדרה ועל הרב המחבר, ותמונות מהשיעורים אם רוצים.
- **עיון בספר:** להציג עמודים לדוגמה מתוך הספרים? אם כן – אילו.
- **פרטים טכניים:** אילו פרטים להציג לכל ספר.
- **כמויות גדולות:** הנחת כמות, או טופס הזמנה מוסדית ליצירת קשר?
