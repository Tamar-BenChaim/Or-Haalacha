# יומן עבודה

מה נעשה בכל שלב, ומה הלאה. הרשומה החדשה ביותר למעלה.

## 2026-10-26 – החלטות

- הגישה למסד: הדרייבר הרשמי `mongodb` (החלטה 0008).
- זמני שמירת הלוגים אושרו: 90 יום ללוג הבקשות, שנתיים ליומן הפעולות (החלטה 0007).
- הדומיין ותיבת המייל רשומים ב־Zoho. לפני העברת ה־DNS ל־Cloudflare מעתיקים את רשומות המייל של Zoho.

## 2026-10-26 – שלד השרת

ענף: `feat/server-skeleton`

- שרת Express 5 עם שכבות: routes → controllers → services (שכבת הנתונים תצטרף עם חיבור המסד).
- אימות משתני סביבה עם zod. השרת לא עולה אם חסר משתנה.
- אבטחה: helmet, ‏CORS לכתובות מורשות בלבד, הגבלת קצב, גבול לגודל הבקשה, חסימת NoSQL injection, הודעות שגיאה שלא חושפות מידע.
- רכיב לאימות קלט (`validate`) לכל נקודת API.
- לוג לכל בקשה, בלי מידע אישי, דרך מאגר בר־החלפה. כרגע לפלט השרת, ובהמשך למסד (החלטה 0007).
- נקודה ראשונה: `GET /health`.
- 42 בדיקות (יחידה ואינטגרציה), ESLint ו־Prettier.
- תיעוד: `server/README.md`, `docs/api.md`, החלטות 0006 ו־0007.

## חשבונות

- GitHub: חוק ההגנה פעיל. Secret scanning, ‏Push protection ו־Dependabot security updates מופעלים.
- Cloudflare: החשבון נפתח, הדומיין נוסף, ושרתי השמות הוחלפו ב־OpenSRS (2026-10-26). ממתינים לאישור ההפעלה. אחר כך: בדיקת המייל והוספת DMARC.
- MongoDB Atlas: טרם נפתח.

## הצעדים הבאים

1. Cloudflare: אישור ההפעלה, בדיקת המייל ו־DMARC.
2. MongoDB Atlas: חשבון, פרויקטים, משתמשים וגישת רשת.
3. שכבת הנתונים עם הדרייבר `mongodb`, ושמירת הלוגים במסד.
4. שלדים של `client/` ו־`admin/`.
