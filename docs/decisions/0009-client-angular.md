# 0009 – חנות הלקוח ב־Angular במקום React

סטטוס: התקבלה (מחליפה את חלק מ־0001)

## הקשר
ב־0001 נקבע שהחנות (`client/`) נבנית ב־React + Vite. עוד לא נכתב קוד בצד הלקוח, ולכן המעבר זול. המפתחת שאחראית על צד הלקוח עובדת ב־Angular.

## החלטה
- `client/` – החנות, ב־**Angular** (Angular CLI, רכיבי standalone, TypeScript).
- `admin/` – נשאר React + Vite עד להחלטה אחרת.
- משתני סביבה: Angular לא קורא קבצי `.env`. כתובת ה־API נשמרת בקבצי `src/environments/`. הם נכנסים ל־git ונשלחים לדפדפן, ולכן **אסור לשים בהם סודות**. אין יותר `client/.env.example`.
- בדיקות רכיבים: כלי הבדיקות של Angular CLI. ב־CI הן רצות פעם אחת, בלי מצב watch.
- שאר העקרונות (RTL בעברית, עגלה ב־localStorage, מחירים מחושבים בשרת, E2E לזרימות קריטיות) לא משתנים.

## נימוקים וחלופות
- הצוות שיבנה את צד הלקוח מכיר Angular, וזה מקצר את הפיתוח.
- Angular כולל מובנה ניתוב, טפסים, HTTP ובדיקות, כך שיש פחות ספריות חיצוניות לתחזק ולסרוק לחולשות.
- חיסרון: שתי טכנולוגיות בצד הלקוח (Angular לחנות, React לניהול), וקוד משותף ביניהן קשה יותר. אם זה יפריע, אפשר להעביר גם את `admin/` ל־Angular בהחלטה נפרדת.
- ה־CI לא משתנה: הוא מריץ `npm ci`, ‏`lint`, ‏`test` ו־`build` לפי ה־scripts שב־`package.json`.
