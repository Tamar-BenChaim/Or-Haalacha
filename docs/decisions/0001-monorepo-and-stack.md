# 0001 – מונו־ריפו וסט הטכנולוגיות

סטטוס: התקבלה

## הקשר
אתר קטן למכירת כ־20 ספרים. צוות קטן, ורצון בשליטה מלאה ובתחזוקה פשוטה.

## החלטה
ריפו אחד (`Or-Haalacha`) עם שלוש תיקיות עבודה:
- `client/` – החנות, React + Vite
- `admin/` – אזור הניהול, React + Vite
- `server/` – Node.js
- מסד נתונים: MongoDB Atlas

## נימוקים וחלופות
- ריפו אחד מאפשר שינוי אחד שנוגע בלקוח ובשרת יחד, ו־CI אחד.
- צד הלקוח של החנות והניהול נפרדים כדי שקוד הניהול לא יישלח לגולשים (ראו 0003).
- נשקלו ריפואים נפרדים, ונפסלו בגלל תקורה גבוהה לפרויקט בגודל הזה.
