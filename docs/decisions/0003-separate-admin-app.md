# 0003 – אפליקציית ניהול נפרדת מאחורי שער הרשאות

סטטוס: התקבלה

## הקשר
צריך אזור ניהול לספרים, הזמנות ודוחות, שאין לגולשים רגילים גישה אליו.

## החלטה
- אפליקציה נפרדת ב־`admin.orhaalacha.org`, בלי שום קישור אליה מהחנות.
- הגנה בשתי שכבות: Cloudflare Access (קוד חד־פעמי למייל מורשה), ובנוסף השרת מאמת בכל בקשת ניהול את האישור החתום של Cloudflare ואת המייל המורשה.
- כתובות: `orhaalacha.org` (חנות), `admin.orhaalacha.org` (ניהול), `api.orhaalacha.org` (שרת).

## נימוקים וחלופות
- הסתרת כתובת אינה אבטחה, ולכן ההגנה האמיתית נמצאת בשרת.
- ההפרדה מבטיחה שקוד הניהול כלל לא נשלח לגולשים.
- נפסלו: מערכת תוכן חיצונית (שני מקורות אמת), ועריכה ישירה במסד הנתונים (מסוכן ולא מתאים למי שאינו מתכנת).
