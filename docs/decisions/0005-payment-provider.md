# 0005 – חברת סליקה

סטטוס: פתוחה

## אילוצים
- דף תשלום מאובטח אצל הספק (hosted / iframe), כך שפרטי אשראי לא עוברים בשרת שלנו.
- אישור תשלום מגיע רק מהשרת של הספק, עם אימות חתימה.
- הפקה אוטומטית של קבלות או חשבוניות, או חיבור לשירות חשבוניות.
- תמיכה בשקלים, ועמלות סבירות לנפח קטן.
- תמיכה בהחזרים דרך ממשק הספק.

## החלטה
טרם התקבלה. תלויה בתשובות הלקוח (סוג העסק, מערכת חשבוניות קיימת).
