# 0004 – אחסון השרת

סטטוס: פתוחה

## הקשר
החנות והניהול הם אתרים סטטיים ויתארחו ב־Cloudflare Pages. נשאר להחליט איפה רץ שרת ה־Node.js.

## אילוצים
- המסד מוגבל לכתובות IP מורשות, ולכן לשרת צריכה להיות כתובת יוצאת קבועה (בלי `0.0.0.0/0`).
- השרת צריך להיות זמין תמיד, בלי "הירדמות" שפוגעת בתשלום ובאישורו.
- עלות חודשית נמוכה ותחזוקה פשוטה.

## אפשרויות להשוואה
AWS (למשל App Runner / ECS / EC2 / Lambda), ושרתים מנוהלים פשוטים יותר. יושוו לפי מחיר חודשי, מורכבות, אבטחה וכתובת IP קבועה.

## החלטה
טרם התקבלה.
